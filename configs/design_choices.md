| 1 Ingest+Enhance | Convert reproducibly rasterized Bangla grammar pages into stable `Page` records without damaging old letterpress glyphs. | Canonical `data/raw/<doc_id>/page_<pdf-page>.png`; blank pages are conservatively detected and non-blank exclusions require explicit page IDs. | No learned model in the baseline; Pillow/NumPy classical image processing. | Deterministic numeric ordering, per-document small-mode limits, projection-profile deskew, 3×3 median denoise, and global Otsu binarization. | Preserve raw files; write derived PNGs to `<artifact_dir>/preprocessed/<doc_id>/`; keep page and document IDs unchanged. | Unit tests use synthetic blank/skewed pages; Kaggle compares preprocessing off/on on six real pages and checks ink-retention ratios plus Bengali-stroke preservation visually. | Paths are controlled by `DOC_AGENT_DATA_DIR` and `DOC_AGENT_ARTIFACT_DIR`; generated files stay in Kaggle working storage. | Config and dependency versions are committed; raw and processed SHA-256 values plus preprocessing measurements are saved in `preprocess_metrics.json`. |
| 2 Layout | Produce valid OCR crops in grammar-book reading order without separating rules from their examples or interleaving table columns. | Preprocessed page images; validation covers historical text, clean NCTB text, headings, numbered rules, exercises, and ruled tables. | Deterministic Pillow/NumPy projection-profile baseline; no learned detector. | Detect foreground line runs, merge nearby aligned lines into blocks, identify repeated long horizontal/vertical rules as one table, and order full-width sections before left-to-right columns. | Preserve the fixed `Page -> Region` contract, exact page IDs, bounded half-open boxes, and the input page order. | Synthetic tests cover determinism, bounds, linkage, atomic tables, and column order; Kaggle overlays numbered boxes on representative real pages. | CPU batch stage with no model download; it reads configured page paths and returns in-memory regions. | Configuration and tested Git commit are recorded; visual coverage and reading-order failures are reviewed before OCR. |
| 3 OCR | Recover Bangla grammar text while preserving conjuncts, matras, hasanta, reph, Bengali digits, punctuation, and rule notation. | Ordered regions plus 12 held-out page images with human-verified transcriptions; the PDF native text layer is never used. | EasyOCR 1.7.2 with `bn+en` is the reproducible operational reader; existing Qwen3-VL 8B drafts are retained as the measured historical comparison. | Crop each region, reconstruct lines geometrically, preserve raw output for evaluation, then apply only NFC and conservative whitespace normalization. | Return stable `Chunk` IDs with exact document/page provenance; load EasyOCR lazily once per run. | Unit tests mock recognition to verify order, IDs, empty-region handling, NFC, and linkage; Kaggle reports raw/normalized CER and WER by document and overall. | GPU when available, otherwise CPU; batch size 8 and zero worker subprocesses for Kaggle stability. | Pin the OCR version, print runtime/device and commit, retain the worst failure, and reconsider the reader only after a like-for-like held-out comparison. |
| 4 Index | Form retrieval units that retain grammar rules, examples, and canonical citations, then persist a restart-safe dense index. | NFC OCR chunks in document/page/region order; every source chunk carries one or more canonical PDF page IDs. | Fixed 256-token/32-overlap baseline and rule-aware structural chunking; selected BAAI/bge-m3 embeddings (1024 dimensions) with FAISS FlatIP. | Start units at Bengali/Latin numbered rules, subsection/chapter headings, and tables; retain examples; L2-normalize exactly one vector per chunk before inner-product search. | Deterministic chunk IDs and ordered page-ID unions; `index.faiss` plus JSON metadata reconstruct every `Chunk` field and fail closed if either artifact is corrupt or inconsistent. | Kaggle evidence on the full corpus selected BGE-M3 + rule-aware chunking: 1,910 chunks, 775 indexed pages, 1024 dimensions, Hit@5 0.5. BGE-M3 fixed also scored 0.5; the rule-aware configuration won the deterministic tie-break. The lightweight multilingual MiniLM baseline scored 0.0. | Index outputs resolve beneath `DOC_AGENT_ARTIFACT_DIR`; the build entry point invokes the fixed pipeline exactly once and never writes beneath Kaggle input storage. | Kaggle run on commit `711c0443f911d49eb02c0ec235e7f002afed2fe1` measured 157.75 s selected-index build time, 7,823,405-byte FAISS index, and 3,327,348-byte metadata. Fresh-process reload passed. The worst query missed its expected page in top five and is retained as an honest failure case. |
